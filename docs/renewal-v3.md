## 2. 役割分担：HP＝選ぶ場所／BASE＝払う場所

```
検索 → 記事(/column) ─┐
Instagram ─────────────┼→ HP: 豆を選ぶ (/beans, /beans/[slug]) → BASE: 個別商品ページで決済
指名検索 → トップ(/) ──┘
```

- HP の商品カード・ボタンは、**BASE のショップトップではなく個別商品ページへ直リンク**する
- ボタン文言は「BASEで購入する」のように、**外部へ移ることが分かる**ものにする
- 全リンクに UTM を付ける（`utm_medium=column|top|beans`、既存の記事UTMを拡張）
- BASE からはやめない。定期便やポイントを本格的にやるときに Shopify を再検討する

## 4. トップ `/` の構成（上から）

1. **ファーストビュー**
   - 1文で何の店か言う。例：「自家焙煎のスペシャルティコーヒー豆を、100gから。」
   - 主CTA「豆をえらぶ」→ `/beans`、副CTA「はじめての方へ」→ `/guide`
   - 手書きロゴと紙の質感は残す。ロード演出は短くし、文字はすぐ読めるようにする
2. **3つの豆**（カード3枚）
   - 写真・名前・焙煎度・味の言葉（3語まで）・価格・1杯あたりの目安（約150円）・「詳しく」→ `/beans/[slug]`
   - 3種しかないので、一覧へ遷移させずに**トップで全部見せる**
3. **味で選ぶ早見表**
   - 「すっきり華やか ←→ どっしりほろ苦」の1軸に3種を配置する
   - 「ミルクを入れるなら」「ブラックなら」など、飲み方からも選べるようにする
4. **飲み比べセット**（§9で商品化が決まった場合のみ）— はじめての人の入口
5. **安心材料**：送料¥350・発送日数・豆／粉の選び方・保存の仕方（→ `/guide`）
6. **人気の読みもの**：GSC上位の記事を3〜4本（淹れ方・産地の地図など）
7. **焙煎者のこと**（短く）→ `/about`
8. **フッター**：日誌・Podcast・アプリ・Instagram・BASE

**やめるもの**：ゆる吸着スクロール、パララックス、セクション見出しの手書き画像のみの表現（テキスト化する）

## 5. 豆の詳細 `/beans/[slug]`（新規）

MUI の商品ページを参考にした構成：

1. 名前・焙煎度・価格・容量・1杯あたり → **「BASEで購入する」**ボタン（ファーストビュー内に置く）
2. 味の言葉＋味のチャート（酸味・苦味・コク・甘み）
3. 産地情報の表（国・地域・農園・品種・精製）— BASE の既存情報を流用する
4. おすすめの飲み方（ブラック／ミルク／淹れ方の目安）
5. この豆に合う読みもの（例：マンデリン → `mandheling-coffee`, `coffee-milk-drinks`）
6. 送料・挽き目・発送の要点 → 再度「BASEで購入する」
7. 構造化データ：`Product`（product snippet 想定。購入はできないページなので、販売者向けリスティングは狙わない）

**重複コンテンツ対策**: HP 側を厚く書き（チャート・飲み方・関連記事）、BASE 側は簡潔にして差をつける。

## 6. 記事テンプレート（`/column/[id]`）

- 記事末尾（と、長い記事は中盤にも）に**「この記事に合う豆」ブロック**を置く
- 紐付けは microCMS `columns` に参照フィールド `relatedBeans`（`beans` への複数参照）を追加して行う。未設定の記事はカテゴリから自動選定（産地記事 → その産地の豆、淹れ方記事 → 全3種）
- ブロックの中身は豆カード（§4-2 と共通のコンポーネント）＋「はじめての方へ」リンク
- UTM は `utm_medium=column`・`utm_content=bean-block`

## 8. デザイン方針

- **残す**：紙の生成り×深緑インク、手書きロゴ、手書きの区切り線（ブランドの手ざわり）
- **変える**：情報を先に出す。見出しはテキスト（手書き画像は飾りに格下げ）、演出は最小限、価格・焙煎度・味は常に見える状態にする
- **SPファースト**：記事流入の多くはスマホ。豆カードと購入ボタンは親指の届く位置に置く

## 9. BASE 側でやること（HPより効果が大きい可能性あり）

1. **入口商品をつくる**：3種の飲み比べセット（例：各50g×3）。MUI の強さの本体はここ
2. 送料無料ラインの検討（例：200g以上・2袋以上）— 「まとめ買い」の理由になる
3. BASE テーマの色・ロゴを HP とそろえ、ヘッダーに HP への戻りリンクを置く
4. 商品名の表記をそろえる（HP と BASE で「マンデリン ポルン」と「マンデリン」がずれている）
